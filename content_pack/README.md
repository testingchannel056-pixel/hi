# Murim Life

A text-based murim life sim for Godot 4.3+ (portrait, 720x1280).
247 events, 737 choices, 29 endings. Not yet run inside the Godot editor.

## Files

| File | Purpose |
|---|---|
| `main.tscn` | One full-rect Control with `main.gd` attached. Set it as the main scene. |
| `main.gd` | All game logic. The UI is built in code in `_build_ui()`. |
| `events.json` | Every event. Generated by `tools/build_events.py`; edit the sources, not this file. |
| `endings.json` | The endings, checked top to bottom at death. First match wins. Edit by hand. |
| `tools/events_src/*.txt` | Event sources in a compact text format (see "Writing events"). |
| `tools/build_events.py` | Validates the sources and writes `events.json`. |
| `tools/simulate.py` | Plays thousands of automated lives to check balance and reachability. |
| `tools/.gdignore` | Makes Godot ignore the `tools` folder. |

## Project settings

- Display > Window > Size: 720 x 1280
- Display > Window > Stretch: Mode `canvas_items`, Aspect `expand`
- GUI > Theme > Custom Font: set your serif font here to apply it everywhere
- Export presets > Resources > "Filters to export non-resource files": add `*.json`

## How a life plays

1. A new game opens with the `origin` event (choose a background).
2. Each turn is one year: age +1, health +`YEARLY_REGEN`, qi + Comprehension. Some flags add yearly effects (`YEARLY_FLAG_EFFECTS`, for example `poisoned`).
3. If qi is full, the breakthrough event (built in `_breakthrough_event()`) is shown. Otherwise one eligible event is drawn by weight. An event does not come back until every eligible event has been seen; `once` events never come back; `repeat` events can come back any year.
4. The player picks a choice. The game rolls against the shown chance and applies the success or fail outcome. An outcome with `goto` chains straight into another event without a year passing.
5. The life ends at 0 health, 0 Dao Heart (qi deviation), old age (`BASE_LIFESPAN + LIFESPAN_PER_REALM * realm`), or an outcome with `die`. The first matching entry in `endings.json` is shown.

## Player state

| Stat | Notes |
|---|---|
| Health, Qi | Qi fills toward a breakthrough. |
| Realm | Mortal, Third-rate, Second-rate, First-rate, Peak, Transcendent, Profound (0 to 6). |
| Body, Movement, Comprehension | Start at 5, +1 each per breakthrough, capped at `8 + realm`. |
| Luck | Capped at 10. |
| Dao Heart | Capped at 12. Reaching 0 ends the life. Dark choices erode it. |
| Gold | Unlocks "pay" choices. |
| Fame, Infamy, Shame | Reputation tracks. They drive the header title, many events, and the endings. |
| Techniques | Unlock extra choices (shown as `[Qi Sense] ...`) and add 1 combat power each. |
| Flags | Hidden story state: memberships, relationships, curses and so on. |

## Formulas

- Stat check: `0.5 + (stat - difficulty) * 0.08`, clamped to 5%..95%. A fixed check uses `difficulty`. A relative check uses `rel`: difficulty is `5 + rel`, plus the realm for Body, Movement and Comprehension.
- Combat: `0.5 + (power - enemy) * 0.04`, clamped to 5%..95%. Player power is `body * 2 + movement + realm * 10 + techniques + flag bonuses` (`POWER_FLAGS`). A fixed enemy uses `power`; a relative enemy is `17 + 13 * realm + rel`.
- Health losses are multiplied by `1 + 0.15 * realm`.
- Breakthrough: Comprehension against `5 + 2 * realm`. Failure costs half of max qi and 15 health. The flag `great_pill` or `blood_art` adds a guaranteed option.

All of these are constants at the top of `main.gd`. `tools/simulate.py` mirrors them in `CFG`; change both together.

## Reputation scale

| Track | Header title steps | Ending tiers (low / mid / top) |
|---|---|---|
| Fame | 10, 25, 60, 100 | 25 / 60 / 100 (the top tier also needs realm 3) |
| Infamy | 8, 15, 40, 75 | 15 / 40 / 75 (the top tier also needs realm 3) |

Shame is the easiest to gain (most shameful choices need no roll), so its numbers run higher.

## Writing events

Add events to any file in `tools/events_src/`, then run `python3 tools/build_events.py` from the project root. The script reports errors (unknown stats, missing goto targets, flags that are required but never set) and rewrites `events.json`.

```
@road_bandits | Bandits on the Mountain Road | realm<=2, !bandit
Three men with rusted sabres block the pass.
* Draw your weapon | fight:the bandits@14
+ They scatter after the first exchange. | fame+1, gold+10
- A blade finds your shoulder. | hp-25, gold-10
* Run for the trees | move:+0
+ Their curses fade behind you. | move+1
- A thrown club catches your back. | hp-15
* Hand over your purse | | gold>=10
+ They take it. | gold-10, shame+1
```

| Line | Meaning |
|---|---|
| `@id \| Title \| conditions` | Starts an event. Lines after it, up to the first choice, are the story text. |
| `* text \| check \| conditions` | A choice. Check and conditions are optional. Every event needs at least one choice with no conditions. |
| `+ text \| effects` | Success outcome. |
| `- text \| effects` | Fail outcome (only for choices with a check). |
| `#` | Comment. |

| Token | Where | Meaning |
|---|---|---|
| `once` | event | Never shown twice in a life. |
| `retry` | event | Can return any year while its conditions hold (exams, cures, cravings). |
| `hidden` | event | Only reachable through `goto`. |
| `w=5` | event | Draw weight. Default 1; 4 if the event requires a flag; 3 if it requires fame, infamy or shame. |
| `age>=16`, `fame<=10` | event, choice | Minimum or maximum of any stat. |
| `cult`, `!cult` | event, choice | Flag must be set / must not be set. |
| `tech=qi_sense` | choice | Requires a technique; shown as a prefix on the button. |
| `body:6` | check | Fixed difficulty 6. |
| `body:+1` | check | Relative difficulty: 1 above the player's baseline. |
| `fight:Name@14` | check | Combat against fixed power 14. |
| `fight:Name~+2` | check | Combat against a foe 2 above the player's realm baseline. |
| `hp-25`, `fame+3` | effect | Change a stat. |
| `learn=iron_shirt` | effect | Teach a technique. |
| `flag=x`, `unflag=x` | effect | Set or clear a flag. |
| `goto=event_id` | effect | Chain into another event immediately. |
| `die` | effect | End the life after this outcome. |

Stat names: `age`, `realm`, `health` (`hp`), `max_health` (`maxhp`), `qi`, `max_qi` (`maxqi`), `body`, `movement` (`move`), `comprehension` (`comp`), `luck`, `dao_heart` (`dao`), `gold`, `fame`, `infamy`, `shame`.

Typical sizes: reputation +1 to +3 for an ordinary deed, +5 to +10 for a turning point; health loss 15 to 45; relative checks `+0` to `+3`; relative fights `+0` to `+4` for ordinary foes, `+5` to `+7` for legends.

## Testing balance

`python3 tools/simulate.py 500` plays 500 lives with each of six simple bots and prints death causes, ending shares and any event that never fired. At the current balance:

| Bot | Avg age | Avg realm | Most common endings |
|---|---|---|---|
| random | 75 | 1.7 | Local Terror 26%, Petty Rogue 19%, Nameless Grave 18% |
| careful | 71 | 1.1 | Nameless Grave 39%, Quiet Life 19%, Local Hero 18% |
| cultivator | 95 | 3.7 | Great Hero 34%, Divine Doctor 17%, Ascended 6% |
| hero | 81 | 2.4 | Great Hero 44%, Legend 25%, Pillar of the Murim 6% |
| villain | 66 | 1.9 | Feared Villain 31%, Local Terror 29%, Calamity 15% |
| scum | 75 | 1.7 | Shameless Scoundrel 59%, Greatest Scumbag 28% |

Known soft spots:

- Most lives end in old age. Death by wounds is rare (0 to 13%). Lower `YEARLY_REGEN` or raise `DAMAGE_PER_REALM` for a deadlier game.
- The greedy villain bot dies of qi deviation in about half its lives. That is the intended risk of the dark path, but `FIXED_CAPS` and the Dao Heart costs in the events are the knobs if it feels harsh.
- Gold has few sinks. Scoundrels end with about 1,800 gold; honest lives with 150 to 250.
