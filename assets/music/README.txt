Background music goes in this folder.

1. Take one music file and name it "background":
	 background.ogg   (best choice for music)
	 background.mp3
	 background.wav
2. Save it in this folder (assets/music).
3. Click on the Godot window so it notices the new file, then run the game.

The game plays it on a loop. The volume is in the game's Settings (the gear
button), under "Music".

Only use music you are allowed to use in a game you sell or show ads in:
music you made, music you paid for with a commercial licence, or music
released as CC0 / public domain. Keep a note of where each track came from.
